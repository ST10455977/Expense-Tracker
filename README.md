# Expense-Tracker
 Vanguard Finance

Vanguard Finance is a modern, intuitive personal finance and budgeting application designed to help users take control of their financial health. Built with a focus on usability and data-driven insights, the app provides a seamless experience for tracking expenses, managing budgets, and planning for future financial goals.

 Features

Expense Tracking: Easily log and categorize daily transactions to monitor spending habits.
Smart Budgeting: Create and manage custom budgets for different categories to ensure financial discipline.
Data Visualization: Interactive charts and summaries to help you understand where your money goes.
Security First: Local data persistence ensures your financial information stays on your device.
Clean UI/UX: A serene, clutter-free interface designed for clarity and ease of use.

 Tech Stack

Language: Kotlin
UI Framework: Jetpack Compose (Modern declarative UI)
Architecture: MVVM (Model-View-View Model)
Database: Room Persistence Library (Local SQLite abstraction)
Asynchronous Programming: Kotlin Coroutines & Flow
Lifecycle Management: Android Architecture Components (View Model, Lifecycle-aware components)

 Installation

1.  Download the `app-debug.apk` file.
2.  Transfer the APK to your Android device.
3.  Enable "Install from Unknown Sources" in your device settings.
4.  Open the file and follow the on-screen prompts to install.

Usage

Dashboard: View your overall financial status at a glance.
Transactions: Tap the '+' icon to add a new income or expense entry.
Budgets: Set limits for specific categories (e.g., Groceries, Entertainment) and track progress.
Settings: Customize your profile and application preferences.
